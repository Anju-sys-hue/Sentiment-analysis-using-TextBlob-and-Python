# Sentiment-analysis-using-TextBlob-and-Python

## Description
This project analyzes text data to determine sentiment trends by classifying entries into positive, negative, and neutral categories. The dataset was cleaned and processed using pandas, and sentiment polarity was computed using TextBlob.

## Tools & Technologies
-Python
-pandas
-TextBlob
-seaborn
-matplotlib

## Workflow
1. Data loading(CSV file)
2. Data cleaning(handling null values, text preprocessing)
3. Sentiment analysis using TextBlob
4. Categorization into positive, negative, neutral
5. Visualization using seaborn and matplotlib

## Results
-Analyzed ~5,000 text records
-Identified sentiment distribution across dataset
-Majoity sentiment observed: Positive
